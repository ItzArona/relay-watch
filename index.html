02

为什么要测

A

回复层投毒

中转可能篡改 system / developer 指令，吞掉 reasoning 字段，或在正常回答里拼入不可见内容。

B

工具层降级

工具 schema 被删除、参数被改写，模型只能“假装调用”，agentic 工作流因此静默失效。

C

能力层伪装

模型名称和计费看起来正确，实际上游被降级为另一个模型，长上下文和多轮执行能力消失。

!

检测结果是启发式信号，不是供应商取证。不要把真实生产密钥用于未知中转站。
